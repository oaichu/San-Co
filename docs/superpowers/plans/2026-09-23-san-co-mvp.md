# Sân Cờ MVP — Implementation Plan

**Goal:** Build the full MVP per spec — 4 board games (caro, chess, xiangqi, go) vs client-side AI (5 levels), username/password auth, online PvP over WebSocket with ELO, interactive lessons + puzzles, Docker all-in-one deploy.

**Architecture:** Next.js 15 App Router + TS + Tailwind v4 + shadcn/ui + Motion. Shared pure-TS game rules in `lib/games/` consumed by UI, AI workers, and the WS server. Custom `server.mjs` (Node) serves Next + `/ws` + `/api/*` + better-sqlite3 at `/data/sanco.db`.

**Tech Stack:** Next.js, React 19, Tailwind v4, shadcn/ui, motion, better-sqlite3, bcryptjs, ws, chess.js, stockfish (wasm via public/), vitest.

**Spec:** `docs/superpowers/specs/2026-09-23-san-co-mvp-design.md`

## Global Constraints

- Copy: tiếng Việt, không em-dash trong UI, CTA một nhãn "Chơi ngay"
- Design: Be Vietnam Pro only (next/font/google), tokens 2 theme `data-theme`, accent vermilion (`#E0552F` dark / `#C7431E` light), no eyebrow/gradient-text/purple/nested-cards/emoji-icons
- Motion: transform/opacity/clip-path only, ease-out `cubic-bezier(0.23,1,0.32,1)`, UI ≤300ms, press `scale(.97)`, `@media (hover:hover)` gate, respect prefers-reduced-motion
- shadcn/ui for primitives; Motion (npm `motion`) for JS-driven animation
- TDD: game rules + engines + ELO + ws validation get vitest coverage
- Commit per task with conventional messages

## Tasks (per milestone)

### M3 — Chess
